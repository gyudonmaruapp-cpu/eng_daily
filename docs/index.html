英語名言 日めくりカレンダー

1日1つ、英語の名言で学ぶ習慣を。

その日をひらくと、英語の名言がひとつ出てきます。それだけのアプリです。和訳と、単語や文法のワンポイント解説がついているので、眺めているうちに少しは英語に触れられます。

明日の分は見られません

今日の名言を読んだら、次は明日まで待つことになります。まとめ読みができないぶん、ひらく理由が毎日生まれる。日めくりカレンダーと同じ仕組みです。 朝の時間を指定しておけば、通知で届きます。

覚えるポイントは、ひとつだけ

たとえば "Rome wasn't built in a day."（ローマは一日にして成らず）には、「"wasn't built" は受け身の過去形」という短いメモがついています。あれもこれもと詰め込みません。その日に持ち帰るのはひとつ。30秒で読み終わります。

読んだ分だけ、残る

アプリをひらいて実際に表示した名言だけが、アーカイブに積み上がっていきます。使わなかった日はさかのぼれません。裏を返せば、溜まった数がそのまま続けた日数になります。 名言や著者名からの検索にも対応しました。気に入った一文はお気に入りに入れておけます。ホーム画面ウィジェットを置けば、アプリをひらかなくても今日の一文が目に入ります。

収録している名言について

365日ぶんを、日付ごとに固定で割り当てています。著作権に配慮し、古くから伝わることわざ・格言と、没後長い年月が経った人物の言葉を中心に選びました。 世の中に出回っている「名言」には、出典があやしいものや、実際にはその人が言っていないものが驚くほど多く混ざっています。有名な言葉ほど、その傾向は強くなります。このアプリでは公開されている資料をもとに1件ずつ出典を確認し、裏付けの取れなかったものは載せていません。この確認作業で、最初に用意した365件のうち6割ほどに手を入れることになりました。
